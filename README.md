# ops-lane/.github

Organisation-wide defaults for all repositories in **ops-lane**.
Files in this repository are used by every repository that does not provide its own version.

## Contents

| Path | Purpose |
|---|---|
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Issue forms: bug report, new feature, technical debt, security issue |
| [`pull_request_template.md`](pull_request_template.md) | Default pull request description |
| [`SECURITY.md`](SECURITY.md) | Security policy and how to report vulnerabilities |
| [`profile/README.md`](profile/README.md) | Public organisation profile shown on github.com/ops-lane |
 

# Conventions

- Everything in this repository is written in **English**.
- Changes go through a pull request.
